## 📌 Sobre o Projeto

O **Java Randomizer CLI** é uma aplicação desenvolvida em **Java 21** para realização de sorteios através do terminal.

O projeto foi criado com foco no desenvolvimento e aprimoramento da lógica de programação, aplicando conceitos fundamentais da linguagem Java de maneira prática.

A aplicação permite realizar diferentes tipos de sorteios de forma simples, rápida e interativa.

---

## ✨ Funcionalidades

- 🎯 Sorteio de um número
- 🔢 Sorteio de vários números
- 👥 Sorteio de participantes
- 🪙 Simulação de cara ou coroa
- 🔄 Menu interativo
- ✅ Validação de opções
- 🚪 Encerramento controlado da aplicação
